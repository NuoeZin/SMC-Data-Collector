# SMC Data Collector

SMC Data Collector 是一个用于获取和整理 simmc 世界网页卫星地图数据的 Android 小工具。

本项目为原项目的 Java 语言重制版本，主要用于从 simmc 地图数据中提取国家、领地等信息，并生成便于查看的统计报告。

## 主要功能

- 解析地图 JSON 数据
- 提取国家及领地信息
- 整理国家、领地和首都数据
- 输出格式的多样

## 系统要求

- Android 4.4及以上
