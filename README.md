# SMC Data Collector

SMC Data Collector 是一个用于获取和整理 simmc（simmc 是一个社区庞大的国家模拟 Minecraft 服务器） 世界网页卫星地图数据的 Android 小工具。

本项目为原项目的 Java 语言重制版本，主要用于从 simmc 地图数据中提取国家、领地等信息，并生成便于查看的统计报告。

## 重构修改

使用 Java 语言重构了主要功能

前版本因为缓存存储的不当设计和主要构建组件的臃肿，导致安装应用后的存储占用非常巨大

现在的重构版本将不会出现这种问题了

## 主要功能

- 解析地图 JSON 数据
- 提取国家及领地信息
- 整理国家、领地和首都数据
- 输出依据时间区分，容易对比不同时间段的排名

## 系统要求

- Android 4.4及以上
